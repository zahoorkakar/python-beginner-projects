# Python Beginner Projects

This repository contains beginner-level Python console applications built while learning Python fundamentals.

## Projects Included

### 1. To-Do List App
Features:
- Add tasks
- View tasks
- Delete tasks
- Save tasks to a file
- Load tasks automatically
- Input validation
- Exception handling

### 2. Expense Tracker
Features:
- Add expenses
- Calculate total expenses
- Display all expenses
- Save expenses to a file
- Load saved expenses
- Input validation

## Concepts Practiced

- Python functions
- Loops
- Lists
- File handling
- Exception handling
- Input validation
- CRUD operations
- Program flow
